# Curated Palettes & Typography Pairings

## 1. Curated Palette Archetypes

### Archetype A: Midnight Obsidian (Developer Tools / High-Tech)
- Background: `#0B0F17` (Deep Obsidian)
- Card Surface: `#131B2E` (Frosted Navy Slate)
- Border / Line: `rgba(255, 255, 255, 0.08)`
- Primary Accent: `#38BDF8` (Electric Cyan)
- Secondary Accent: `#818CF8` (Soft Violet)
- Text Primary: `#F8FAFC`
- Text Muted: `#94A3B8`

## 2. Typography Pairings (Google Fonts)

| Pairing Style | Heading Typeface | Body Typeface | Best Use Case |
| :--- | :--- | :--- | :--- |
| **Modern Geometric** | `Plus Jakarta Sans` or `Outfit` | `Inter` | Tech startups, SaaS dashboards, developer tools |
| **Editorial Prestige** | `Playfair Display` or `Fraunces` | `Plus Jakarta Sans` | Fintech, high-end content, luxury services |
| **Clean Technical** | `Space Grotesk` | `JetBrains Mono` / `Inter` | Crypto, security tools, developer utilities |
| **Humanist Friendly** | `Cabinet Grotesk` or `General Sans` | `Inter` | Consumer apps, educational platforms |
