# Source & License Attribution Document

This repository synthesizes research, best practices, and engineering methodologies from leading open-source repositories to build an extensible, production-ready AI skill library.

All skills in this repository are original works engineered specifically for AI coding agents operating in Google Antigravity, Gemini, and multi-agent harnesses. They adapt, distill, and modernize established industry practices without verbatim copying of source files.
