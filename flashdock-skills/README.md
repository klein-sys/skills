# FlashDock Skills Pack (`flashdock-skills/`)

This directory contains the full collection of **50 agent skills** installed, used, and created during the development of **FlashDock** (from `FlashDock\.agents\skills`).

---

## Highlights

- **`flashdock-workstation`**: The proprietary architectural standard for FlashDock (zero-brick guarantees, radio calibration backups `efs`/`nvram`/`persist`, QThread async workers, macOS Big Sur design tokens, version bumping).
- **`android-cli`**: Android device tools, ADB, Fastboot, and emulator automation.
- **Workflow & Engineering Skills**: Full suite of interactive loops (`grill-me`, `handoff`, `teach`, `to-spec`, `to-tickets`, `tdd`, `code-review`, `diagnosing-bugs`, `wayfinder`, `wizard`).
- **Antigravity Customizations**: `agy-customizations`, `antigravity_guide`, `Readme-gen`, `permissioned-github`.

---

## Directory Structure

Skills are present both flat for rapid discovery and organized under category sub-namespaces:
- `engineering/`
- `productivity/`
- `in-progress/`
- `misc/`
